# Employee Attrition BI Dashboard

## Project Overview

This project is an end-to-end Business Intelligence analysis of employee attrition. The goal is to explore workforce data, identify characteristics associated with employee turnover, and develop an interactive dashboard that can support HR decision-making.

The project follows a BI workflow using Python for data profiling, exploratory analysis, and data preparation; SQL for data storage, transformation, and analysis; and Power BI for data modeling, visualization, and reporting.

> **Project Status:** In Progress

## Business Problem

Employee turnover can affect workforce stability, productivity, and organizational costs. HR teams need visibility into attrition patterns and the workforce characteristics associated with employees leaving the organization.

This project will develop a centralized BI solution that allows HR stakeholders to explore employee attrition and identify areas that may warrant further investigation.

## Research Question

**What workforce characteristics are associated the most with employee attrition?**

## Project Objectives

- Analyze overall employee attrition and workforce composition.
- Explore attrition across departments, job roles, demographics, compensation, overtime, and tenure.
- Identify workforce characteristics associated with higher or lower attrition.
- Prepare and structure HR data for analytical reporting.
- Develop an interactive Power BI dashboard for HR decision support.
- Translate analytical findings into actionable business recommendations.

## Tools & Technologies

- **Python** — Data profiling, exploratory data analysis, cleaning, and preparation
- **SQL** — Data storage, transformation, querying, and analytical views
- **Power BI** — Data modeling, DAX measures, dashboard development, and visualization
- **Git/GitHub** — Version control and project documentation
